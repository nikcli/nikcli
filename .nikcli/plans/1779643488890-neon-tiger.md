# Plan: Add Inference Provider Transforms

## Problem

DeepSeek su nikcli-inference gateway rifiuta array content per messaggi user/system.
Errore: `messages.1.content: Expected string, received array`

## Provider

- nikcli-inference gateway (`https://inference.nikcli-ai.dev/v1`)
- DeepSeek models usano `@ai-sdk/openai-compatible`

## Fix

### File: `src/provider/transform.ts`

Aggiungere nuovo blocco dopo DeepSeek (linea 184):

```typescript
// ── nikcli-inference / OAI-Compatible Providers ─────────────────────────────
// nikcli-inference gateway expects string content, not arrays
if (
  model.providerID === "nikcli-inference" ||
  (model.api.npm === "@ai-sdk/openai-compatible" &&
    !model.api.id.toLowerCase().includes("deepseek") &&
    !model.api.id.toLowerCase().includes("mistral"))
) {
  msgs = msgs.map((msg) => {
    if (!Array.isArray(msg.content)) return msg

    // Skip assistant messages (they may contain tool calls)
    if (msg.role === "assistant") return msg

    // Convert array to string for user/system messages
    const text = msg.content
      .filter((p) => p.type === "text" || p.type === "reasoning")
      .map((p) => (p as any).text ?? "")
      .join("\n")
      .trim()

    return { ...msg, content: text || " " } as ModelMessage
  })
}
```
