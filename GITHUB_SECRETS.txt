GitHub Repository Secrets
========================
Aggiungi questi secret in: https://github.com/nikcli/nikcli/settings/secrets/actions

OBBLIGATORI (per npm publish):
-------------------------------
NPM_TOKEN [CONFIGURATO ✓]
  Il token npm per pubblicare i pacchetti.
  Come rinnovarlo: npmjs.com → Profile → Access Tokens → Generate New Token (Granular/Automation)

SST_GITHUB_TOKEN [CONFIGURATO ✓]
  GitHub OAuth token con permessi su repo, packages, write.
  ATTENZIONE: token OAuth (gho_) scadono - se il workflow fallisce, rinnova con: gh auth token

OPZIONALI (per Desktop/Tauri build):
--------------------------------------
APPLE_CERTIFICATE
  Certificato Apple Developer in formato base64 (.p12).
  Necessario per firmare la app macOS.

APPLE_CERTIFICATE_PASSWORD
  Password del certificato .p12 Apple.

APPLE_API_KEY
  Chiave Apple App Store Connect API (contenuto del file .p8).

APPLE_API_ISSUER
  Issuer ID dell'Apple App Store Connect API.

APPLE_API_KEY_PATH
  Path locale della chiave API Apple (di solito non serve come secret, ignorabile).

TAURI_SIGNING_PRIVATE_KEY
  Chiave privata per firmare gli aggiornamenti Tauri (updater).
  Genera con: bunx tauri signer generate

TAURI_SIGNING_PRIVATE_KEY_PASSWORD
  Password della chiave privata Tauri.

OPZIONALI (per il build Android firmato - workflow "mobile-android"):
----------------------------------------------------------------------
ANDROID_KEYSTORE_BASE64
  Keystore di upload (.jks) codificato in base64.
  Genera la chiave (una volta sola, poi conservala: se la perdi non puoi piu'
  aggiornare l'app sul Play Store):
    keytool -genkeypair -v -storetype PKCS12 -keystore nikcli-upload.jks \
      -alias nikcli-upload -keyalg RSA -keysize 2048 -validity 10000
    base64 -i nikcli-upload.jks | pbcopy

ANDROID_KEYSTORE_PASSWORD
  Password dello store (quella chiesta da keytool con "Enter keystore password").

ANDROID_KEY_ALIAS
  Alias della chiave dentro il keystore (es. nikcli-upload).

ANDROID_KEY_PASSWORD
  Password della chiave. Con -storetype PKCS12 coincide con ANDROID_KEYSTORE_PASSWORD.

OPZIONALI (altri):
------------------
AUR_KEY
  Chiave SSH privata per pubblicare su AUR (Arch Linux User Repository).
  Solo se vuoi supportare Arch Linux.

NIKCLI_API_KEY
  API key interna di nikcli (se necessaria per il build).

NOTE:
-----
- GITHUB_TOKEN è automaticamente disponibile in GitHub Actions, non serve aggiungerlo.
- Per il solo publish npm bastano NPM_TOKEN e SST_GITHUB_TOKEN.
- Il publish su npm avviene automaticamente ad ogni push su branch "dev".
- Per un release completo usa workflow_dispatch con bump=patch/minor/major.
